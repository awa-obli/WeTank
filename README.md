# 坦克动荡

Node.js 编写的网页坦克动荡游戏，支持局域网联机。

## 特性

- **4 种模式 × 团队、暗黑模式**：大乱斗、占点、收集、经典；团队模式与暗黑模式均可独立开关
- **5 种地图 × 3 档尺寸**：迷宫 / 空旷 / 对称 / 散块 / 随机，9×6、12×8、15×10
- **服务端权威**：30Hz 物理模拟 + WebSocket 广播，2–10 人同房，支持观战
- **完整对局规则**：初始血量、弹药装填、出生保护、阵亡复活、房主设置
- **键鼠与触屏**：WASD / 方向键 + 空格；手机自动显示虚拟摇杆或十字键

## 快速开始

需要 Node.js 18 及以上。

```bash
npm install
npm start
```

启动后访问 <http://localhost:8080>，叫上好友一起战斗吧！

## 操作说明

| 操作 | 键鼠 |
| --- | --- |
| 前进 / 后退 | `W` / `S` 或 `↑` / `↓` |
| 左转 / 右转 | `A` / `D` 或 `←` / `→` |
| 开火 | `空格` |

触屏设备会自动显示虚拟摇杆，可在设置里切换为十字键。

## 模式说明

| 模式 | 玩法 | 胜利条件 |
| --- | --- | --- |
| 大乱斗 | 连续死斗，阵亡 10 秒后随机复活 | 击杀数达标 |
| 占点 | 站圈 10 秒占领，据点随机换位 | 占领次数达标 |
| 收集 | 抢钻石，阵亡掉落一半 | 收集数达标 |
| 经典 | 回合淘汰赛，活到最后 | 回合胜场达标 |

团队模式、暗黑模式是独立于具体模式的一个开关

- **团队模式**：开启后玩家分为红蓝两队进行对抗；
- **暗黑模式**：开启后玩家视野受限。

## 道具说明

| 道具 | 效果 |
| --- | --- |
| 护盾 | 抵挡一次伤害 |
| 加速 | 6 秒内移动与转向 ×1.5 |
| 隐身 | 8 秒内不被其他玩家看见 |
| 三连发 | 下一发打出扇形 3 颗子弹，只消耗 1 发弹药 |
| 追踪弹 | 下一发子弹自动追踪敌人 |
| 激光 | 一次性反弹射线，命中路径上的所有敌人 |
| 维修包 | 回复 1 点血量 |
| 弹药箱 | 弹药补满（上限 5 发） |

## 项目结构

```
server.js       HTTP + WebSocket 服务、房间与对局逻辑
physics.js      圆-矩形扫掠碰撞与子弹反弹
maps.js         迷宫 / 空旷 / 对称 / 散块地图生成
spawn.js        出生点与复活点选择
capture.js      占点模式：据点生成与进度状态机
laser.js        激光路径与命中计算
public/         前端页面、样式与 Canvas 渲染
public/vision.js 暗黑模式视野：射线求交、墙体遮挡与可见多边形
tests/          单元测试与 WebSocket 端到端测试
```

## 测试

```bash
npm test          # 单元测试，无需启动服务

# 端到端测试：先在另一个终端执行 npm start
npm run test:e2e  # 默认连 ws://127.0.0.1:8080
```
